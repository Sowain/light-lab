# مختبر انكسار الضوء والعدسات

مختبر تفاعلي بالعربي لطلاب المتوسط والثانوي، يشرح كيف يتصرف الضوء لما ينتقل بين الأوساط.

**افتح المختبر:** https://sowain.github.io/light-lab/

## وش فيه؟

1. **الانكسار بين وسطين:** اسحب مصدر الليزر، واختر الوسطين (هواء، ماء، زجاج، ألماس). تشوف الشعاع الساقط والمنكسر والمنعكس، والزوايا، وقانون سنل محسوب مباشرة، والزاوية الحرجة والانعكاس الكلي الداخلي.
2. **العدسات:** عدسة محدّبة ومقعّرة، مع منزلقات للبعد البؤري وبعد الجسم. ترسم الأشعة الرئيسية الثلاثة، وتوضح نوع الصورة (حقيقية أو تقديرية، مقلوبة أو معتدلة، مكبّرة أو مصغّرة) مع معادلة العدسة.
3. **المنشور:** الضوء الأبيض يتحلل لألوان الطيف، مع منزلق لزاوية السقوط وزاوية رأس المنشور.

وكل قسم فيه بطاقة شرح مبسّطة وسؤال "جرّب بنفسك".

## التقنية

صفحة ثابتة: ملف `index.html` وملف `style.css` وملف `lab.js`، بدون أي مكتبات خارجية وبدون خطوة بناء. الرسم كله على `canvas` ومحسوب بالكود.

## التشغيل محلياً

افتح ملف `index.html` في المتصفح مباشرة.
